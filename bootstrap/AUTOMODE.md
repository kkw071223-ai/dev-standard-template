# 자동 승인 모드 설정

Claude Code에는 권한 모드가 6개 있다. 이 설계에 관련된 것은 셋이다.

| 모드 | 묻지 않고 실행되는 것 | 쓸 자리 |
|---|---|---|
| `default` (Manual) | 읽기만 | 기본값. 매번 물어봄 |
| `acceptEdits` | 읽기 + 파일 편집 + `mkdir` `mv` `cp` `rm` 등 | 코드 보면서 반복 작업 |
| **`auto`** | **전부. 백그라운드 안전성 검사를 거침** | **긴 작업. 지금 우리가 쓸 것** |
| `dontAsk` | 미리 허용한 것만. 나머지는 **거부** | CI·스크립트. **나중에 Conductor가 쓸 것** |
| `bypassPermissions` | 전부. 검사도 없음 | 격리된 컨테이너·VM 전용 |

## 지금 쓸 것: `auto`

Claude Max 구독이면 사용 가능하다. 셋 중 아무거나:

```powershell
# 1) 이번 세션만
claude --permission-mode auto

# 2) 세션 중 전환 — Shift+Tab 을 눌러 모드를 순환
#    상태 표시줄에 "auto mode on" 이 뜨면 켜진 것

# 3) 항상 기본값으로 (권장)
```

3번은 **반드시 사용자 설정 파일**에 넣는다. `C:\Users\<you>\.claude\settings.json`:

```json
{
  "permissions": {
    "defaultMode": "auto"
  }
}
```

> ⚠ **프로젝트 폴더의 `.claude/settings.json`에 넣으면 무시된다.** repo가 스스로에게
> auto 모드를 부여하지 못하게 하는 의도적 제한이다. 사용자 설정에 넣어야 먹는다.
> 넣었는데 세션이 `default`로 시작하고 오류도 없다면 십중팔구 이 문제다.

## 넣자마자 해야 할 일 — 게이트 복구

**auto 모드는 기본적으로 이걸 허용한다:**

- 작업 중인 repo의 **아무 브랜치에나 push** (기본 브랜치 포함)
- 요청에 부합하는 **PR 생성**

설계서 §12는 이 둘을 승인 게이트로 두기로 했다. **auto 모드가 그 게이트를 열어버린다.**
같은 파일에 `ask` 규칙을 추가해 되돌린다:

```json
{
  "permissions": {
    "defaultMode": "auto",
    "ask": [
      "Bash(git push:*)"
    ]
  }
}
```

대화로 "push하지 마라"라고 말해도 분류기가 차단 신호로 받아들이지만, **문맥 압축으로
그 메시지가 사라지면 경계도 사라진다.** 공식 문서가 "확실한 보장이 필요하면 규칙으로
넣으라"고 명시한다. 그래서 프롬프트의 게이트 문구와 이 `ask` 규칙을 **둘 다** 둔다.

## auto 모드가 멈출 때

분류기가 **연속 3회** 또는 **누적 20회** 차단하면 auto 모드가 일시 정지하고 다시
물어보기 시작한다. 임계값은 조정할 수 없다. 허용되는 동작 하나가 연속 카운터를
초기화한다.

거부된 동작은 `/permissions` → Recently denied 탭에 쌓인다. `r`을 누르면 수동 승인으로
재시도한다.

> **무인 실행(`claude -p`)에서는 다르다.** 물어볼 사람이 없으므로 반복 차단은 세션을
> **중단**시킨다. Conductor 입장에서는 오히려 이게 낫다 — 멈춰서 기다리는 것보다
> 죽는 편이 §10의 재시도·에스컬레이션으로 넘기기 쉽다.

## 나중에: Conductor는 `dontAsk`를 쓴다

공식 문서의 권고가 그렇다 — *"CI나 스크립트에는 명시적 허용 목록과 함께 `dontAsk`.
목록에 없는 것은 기다리지 않고 실패한다."*

무인 루프에서 중요한 건 "똑똑하게 판단"이 아니라 **예측 가능성**이다. 허용 목록에
없으면 즉시 실패하고, Conductor가 그걸 잡아 §10의 DIAGNOSE로 보낸다. Phase 11에서
Conductor를 세울 때 이 모드로 전환한다.

```powershell
claude -p "<잡>" --permission-mode dontAsk --allowedTools "Read,Write,Edit,Bash,Glob,Grep"
```

## 참고 — 2026-08-14부터

공식 발표에 따르면 **2026년 8월 14일부터 Pro/Max/Team 신규 세션의 기본 모드가
`auto`로 바뀐다.** 나흘 뒤다. 직접 설정한 기본값은 유지되므로, 위 설정을 넣어두면
그 전환과 무관하게 의도한 대로 동작한다.

```

```

현재 모드와 적용 중인 규칙이 보인다. 상태 표시줄에 `⏵⏵ auto mode on` 이면 켜진 것.
